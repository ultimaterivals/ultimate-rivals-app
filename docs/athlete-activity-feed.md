# Athlete activity feed

The personal feed is derived from auditable notifications and homologated match facts. It is not a social network and has no posting, reactions, comments, or follower model.

Each item has a stable key, title, short non-sensitive detail, action route, occurrence time, and unread state. Stable keys prevent duplicate display. Match items link to participant-scoped details; notification items link only to `/athlete` routes.

No e-mail, phone, birth date, full legal name, emergency contact, or internal metadata is copied into feed content.
