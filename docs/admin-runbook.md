# Admin runbook

Admin opera:

- atletas, equipes, polos e temporadas;
- calendario, staff, UR Play e torneios;
- pagamentos, premios, repasses e financeiro;
- venues, sponsors, UR Events, Market, midia e relatorios.

Use `/admin` como cockpit. Pendencias criticas aparecem por pagamentos, deliveries, redemptions e obrigacoes financeiras.
