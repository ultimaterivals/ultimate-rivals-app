# Fonte operacional C41

O Playbook Operacional UR determina, no pós-evento, agradecimento e relacionamento com participantes, anúncio da próxima oportunidade e a pergunta de recomendação de 0 a 10: “De 0 a 10, o quanto você recomendaria o UR para um amigo?”. O mesmo material registra como meta interna manter essa medida acima de 8 e inclui NPS entre os indicadores da análise posterior ao evento.

A C41 preserva essa escala como `Nota média UR` e, para evitar confusão conceitual, apresenta o cálculo padrão de NPS separadamente.
