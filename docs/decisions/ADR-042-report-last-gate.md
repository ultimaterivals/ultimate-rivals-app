# ADR-042 — Relatório é o último gate do Pós-Sessão 360

## Decisão

`Relatório & Aprendizados` é a nona e última frente do fechamento pós-sessão. Ela não pode ser finalizada enquanto uma das oito frentes anteriores ainda estiver pendente.

## Motivo

Uma retrospectiva feita antes de Ranking, Financeiro, Segurança, Mídia, Retenção ou Feedback estarem consolidados produz conclusões sobre dados incompletos. O relatório deve congelar o estado final conhecido da sessão, não uma leitura intermediária.

## Ação não é fechamento

O relatório exige pelo menos uma próxima ação com responsável e prazo, mas essa ação não precisa estar concluída para fechar o 360. A melhoria pertence ao ciclo seguinte e continua rastreável depois do fechamento da sessão.
